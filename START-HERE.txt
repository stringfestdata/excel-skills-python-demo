PYTHON SCRIPTS IN AN EXCEL CUSTOM SKILL
Stringfest Analytics

1. Extract this ZIP before opening files.
2. Open python-skills-practice.xlsx. It starts with one Data sheet and six rows.
3. In Excel's Copilot settings, open Manage skills (or Manage plugins & skills),
   then Custom skills. Open the OneDrive skills folder; create it if needed.
4. Copy the entire expense-check-python folder into that skills folder.
   SKILL.md must sit directly inside expense-check-python, with scripts beside it.
   Do not copy the whole download or only SKILL.md.
5. Let OneDrive sync, refresh the skills list, and enable the skill if necessary.
6. In the practice workbook, send PASS 1 from practice-prompts.txt.
7. Check the result: six rows, with Food and Repairs marked Yes.
   Supplies is exactly $500 over budget and should say No.
8. Change Data!C7 (Supplies actual) from 1500 to 1501, then send PASS 2.
   Supplies should now say Yes. Three expenses should be flagged.

The setup requires Copilot workbook editing, Custom skills and an available
Python execution tool in that Copilot session. You do not need a GitHub account,
Git software, or a local Python installation for the demonstrated Copilot path.
If Copilot cannot execute Python or read the file, stop at that message.
Adding a scripts folder does not add an execution tool to your account.

ExpenseCheck is a snapshot of a Python run. Changing Data alone does not refresh
it. Rerun the skill after each change. This is separate from Python in Excel's
=PY() worksheet feature, VBA and Office Scripts.

All data and the $500 threshold are fictional teaching examples.
The supporting-files folder is optional. It contains developer checks and a
sample CSV for independent testing; Copilot must read the current Excel table.
